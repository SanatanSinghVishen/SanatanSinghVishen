**💫 About Me**
I am a 3rd-year Computer Science Engineering student at IIIT Nagpur, specializing in building scalable full-stack applications and decoupled microservices. My passion lies in bridging the gap between Machine Learning and Web Development, with hands-on experience in engineering real-time data pipelines, asynchronous message brokers using Redis, and self-healing AI architectures. I actively solve algorithmic challenges, having conquered over 350 problems on Codeforces and 300+ DSA problems on LeetCode.

**🚀 Current Projects**
I am currently maintaining several live full-stack applications. You can explore **[Tracel](https://tracel-frontend.vercel.app)**, a real-time network traffic analysis platform built with a decoupled Node.js and Python microservices architecture using Redis (view the **[Source Code](https://github.com/SanatanSinghVishen/Tracel)**). I also architected **[CVision](https://cvision-frontend.vercel.app/)**, an ultra-low latency AI-powered resume optimizer integrating Groq's Llama-3 model and BullMQ job queues (view the **[Source Code](https://github.com/SanatanSinghVishen/CVision)**). Additionally, I developed **[TravelStay](https://travel-stay-sigma.vercel.app/)**, a secure accommodation review platform with an asynchronous job queue for media processing (view the **[Source Code](https://github.com/SanatanSinghVishen/TravelStay)**).
